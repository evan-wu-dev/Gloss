# 字里行间（Gloss）

[English](README.md) · **简体中文**

字里行间是一个 macOS 菜单栏小工具：在任何应用里打字时，它会把你正在写的这句话翻译出来，显示在光标下方的小浮窗里。写母语，就能看到这句话用外语怎么说；写正在学的外语，它会帮你改得更地道。过程中遇到的生词会自动收集起来，方便之后复习。

英文名 Gloss 来自古代抄本里写在行与行之间的小字注释和翻译，中文名「字里行间」也是这个意思：译文就出现在你写的字的下面。

## 功能

- **任意输入框都能用**：通过 macOS 辅助功能读取光标所在的句子，聊天软件、邮件、浏览器、编辑器里都能用，不用装插件。
- **只翻光标所在的这一句**：停顿一下（默认 0.6 秒）才开始翻译；拼音还没上屏时不翻；密码框一律跳过。
- **翻译或润色**：写母语时翻译；写在学的语言时给出更地道的写法，删掉的词划线，加上的词标绿。
- **流式出字**：译文一个字一个字打出来，等待时边框有一圈彩色流光。
- **一键替换**：按 ⌃⌥E，或点浮窗上的替换按钮，把整句换成译文。
- **朗读**：用 macOS 自带的语音，可以按快捷键（⌃⌥S）朗读，也可以在译文出来后自动朗读。
- **自动积累生词**：模型按你的水平挑出 0～3 个值得学的词。见过不到 3 次的生词前面有个橙点，右键可以标记「认识了」，全部生词能导出到 Anki。
- **模型自己选**：支持 OpenAI 兼容接口，比如 DeepSeek、智谱 GLM、通义千问、Kimi、OpenAI，可以在设置里添加、编辑、切换。
- **七种语言**：中文、英语、日语、韩语、西班牙语、法语、德语。翻译语言和软件界面都支持这七种。

## 运行环境

- macOS 13 Ventura 及以上，Apple 芯片
- 一个 OpenAI 兼容模型服务的 API Key
- 辅助功能权限：读取和替换其他应用里的文字需要这个权限

## 构建

项目不依赖 Xcode 工程，构建脚本直接用 `swiftc` 编译并签名：

```bash
./scripts/build.sh
```

产物在 `dist/Gloss.app`，构建最后会自动跑一遍自检。脚本默认用一个固定证书签名，这样每次重新构建后辅助功能授权不会失效。要换成你自己的证书：

```bash
SIGNING_IDENTITY="Apple Development: Your Name (XXXXXXXXXX)" ./scripts/build.sh
```

## 第一次使用

1. 打开 `dist/Gloss.app`，菜单栏会出现「文/A」图标。
2. 系统弹出提示时，到 **系统设置 → 隐私与安全性 → 辅助功能** 里允许 Gloss。
3. 打开 **设置…（⌘,）→ 模型**，编辑已有的模型或添加新模型，填上 API Key。
4. 在 **语言** 页选好母语、在学的语言和你的水平。
5. 在任意输入框里开始打字。

菜单栏图标太多、找不到图标时，在 Spotlight 里再打开一次 Gloss，会直接弹出设置窗口。

## 怎么用

| 想做的事 | 操作 |
| --- | --- |
| 把这句换成译文 | ⌃⌥E，或鼠标移到浮窗上后点 ↩ 按钮 |
| 朗读译文 | ⌃⌥S，或点喇叭按钮 |
| 复制译文 | 点复制按钮 |
| 听某个生词 | 点击这个词 |
| 标记为认识了 | 右键点击这个词 |
| 收起浮窗 | 按 Esc、回车发送消息，或停 15 秒不动 |
| 暂时关掉 | 菜单第一行的开关，关掉后图标会变灰 |

两个快捷键都可以在 **设置 → 快捷键** 里改：点一下按钮，再按下新的组合键。

## 设置

| 页面 | 内容 |
| --- | --- |
| 通用 | 界面语言、总开关、开机自动启动、纠错润色、流式输出、停顿多久开始翻译、自动收起时间 |
| 语言 | 母语、在学的语言、我的水平（CEFR A1～C2） |
| 模型 | 模型列表、切换当前使用的模型、添加 / 编辑 / 删除；「高级」里可以填额外参数 |
| 朗读 | 关闭 / 按快捷键 / 自动朗读，选声音、调语速、试听 |
| 快捷键 | 替换和朗读的快捷键 |
| 外观 | 流光配色：极光、冷蓝、日落、单色 |

所有设置都存在 `~/Library/Application Support/LiveTranslate/config.json`，也可以直接手动编辑。这个文件里有 API Key，创建时权限就设成了 `600`。

### 额外参数

有些模型会先「思考」再回答，翻译因此变慢。在 **模型 → 编辑 → 高级** 里可以填额外参数，它们会合并进每次请求。例如：

- DeepSeek：`{"reasoning_effort":"none"}`
- 智谱 GLM：`{"thinking":{"type":"disabled"}}`

如果接口不认这些参数，会自动去掉再重试一次。实测 DeepSeek 关掉思考后，一句大约 1.4 秒；不关大约 2.8 秒。

## 生词本和 Anki

生词按语言分别保存在 `~/Library/Application Support/LiveTranslate/vocab-<语言>.json`。一句话写完才算「见过」一次，写到一半停顿不重复计数。

点菜单里的 **导出生词到 Anki**，会在「下载」文件夹生成一个用制表符分隔的文件。在 Anki 里选 **文件 → 导入**，选中这个文件即可。卡片正面是单词；背面是释义、你当时写的那句话和它的译文。Anki 按卡片正面识别重复，按默认导入选项再导入一次时，已有的卡片会更新，不会重复。

## 隐私

- 光标所在的句子只会发给你自己配置的模型服务，Gloss 没有自己的服务器。
- 密码输入框一律不读。
- API Key 只保存在本机的配置文件里。

## 已知限制

- **网页技术做的终端**（比如 Orca 等基于 xterm.js 的终端）不会把你正在输入的那一行暴露出来，Gloss 只能读到片段，所以可能只翻译出半句。
- 少数 Electron / Chromium 应用不支持通过辅助功能选中文字，这时会改用 ⇧← 选中再粘贴的方式替换。
- 目前只构建 Apple 芯片版本。

## 项目结构

```
Sources/
  main.swift                  应用入口、主循环、菜单、自检、--demo 演示模式
  Accessibility.swift         读取聚焦的输入框、光标位置、替换文字
  Sentence.swift              取光标所在的句子、判断拼音组字
  Language.swift              支持的语言和语言识别
  LLMClient.swift             OpenAI 兼容接口、流式（SSE）、提示词
  Overlay.swift               浮窗：流光、逐字出现、悬停工具栏、生词标签
  Diff.swift                  润色前后按词对比
  Settings.swift              设置窗口（SwiftUI）
  Localization*.swift         七种语言的界面文案
  Vocab.swift / Speech.swift  生词本、朗读
assets/AppIcon-1024.png       应用图标源图（构建时生成 AppIcon.icns）
scripts/build.sh              构建、签名、自检
```

不想真的去打字、只想看看浮窗效果，可以运行 `dist/Gloss.app/Contents/MacOS/Gloss --demo <waiting|streaming|refreshing|done|polish> [aurora|ocean|sunset|mono] [--light]`。
